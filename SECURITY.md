# Portfolio snapshot security boundary

- Local records and generated credentials are ignored by Git.
- There is no production database connection or shared admin password in this snapshot.
- Optional cloud configuration must use the reviewer's own project and server-side secrets.
- Production data exports, payment proofs, admin screenshots, logs, environment files, and the private repository history are not part of this repository.
- This snapshot has been checked for embedded credentials and tested locally. It is not a claim of a comprehensive security audit or a guarantee against vulnerabilities.
- Report suspected exposure privately to the repository owner; do not publish customer data or credential values in issues.
