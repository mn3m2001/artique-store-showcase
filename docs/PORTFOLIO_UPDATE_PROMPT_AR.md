# برومبت تحديث مشروع آرتيك في البورتفوليو

حدّث مشروع Artique Store الموجود بالفعل في البورتفوليو ليعرض النسخة الجديدة المنشورة، مع الحفاظ على تصميم البورتفوليو وطريقة عرض مشاريعه الحالية وعدم تكرار المشروع.

الموقع المنشور: https://artique-store.vercel.app/

المتجر: https://artique-store.vercel.app/products

الكود العام المخصص للعرض: https://github.com/mn3m2001/artique-store-showcase

التحديثات التي يجب إبرازها:

- افتتاحية تفاعلية مبنية بـ Three.js تعرض صور المنتجات داخل إطارات ثلاثية الأبعاد مع حركة الكاميرا والانتقال بين المنتجات.
- صور وأسعار وحالة توفر المنتجات المنشورة تُقرأ من بيانات المتجر عند فتح الجولة. إضافة منتج منشور بصورة أو تعديل سعره ينعكس عند إعادة تحميل الصفحة.
- هوية موحدة بألوان الكريمي والوردي والذهبي، مع هيدر وقوائم وكروت Liquid Glass وتأثير الميل للكروت على الكمبيوتر.
- تحسين كروت الموبايل: مساحة مربعة ثابتة للصورة، ثم المعاينة والاسم والسعر في أقسام منفصلة، وأزرار تصفية مناسبة للشاشات الصغيرة.
- متجر عربي/إنجليزي يدعم RTL، والتصنيفات والبحث والتصفية والمعاينة السريعة وخيارات المنتجات والسلة وإتمام الطلب، مع لوحة إدارة وربط Supabase واستضافة Vercel.

راجع الموقع الحالي والتقط صورًا جديدة للرئيسية والافتتاحية والمتجر وتفاصيل المنتج، على الكمبيوتر والموبايل، ثم استبدل صور ووصف مشروع آرتيك القديمين في البورتفوليو. الصور الموجودة قديمًا داخل docs/screenshots في المستودع تمثل التصميم السابق.

اكتب وصفًا مختصرًا واحترافيًا يناسب لغة البورتفوليو، وحدّث التقنيات وروابط Live Demo وSource Code والنصوص البديلة للصور. التقنيات: Next.js، React، TypeScript، Three.js، Tailwind CSS، Supabase، Vercel.

صف العرض بدقة: هو مشهد ثلاثي الأبعاد يعرض صور منتجات، ولا تصفه كمسح ثلاثي الأبعاد للمنتجات أو عارض يدور حول نموذج حقيقي لكل منتج. استخدم الواجهات والبيانات العامة فقط في صور البورتفوليو.

بعد التعديل، راجع ظهور المشروع على الكمبيوتر والموبايل، وعمل الروابط، ووضوح الصور والوصف.
