# آرتيك — نسخة عرض للبورتفوليو

الموقع الحقيقي: https://artique-store.vercel.app/

هذه نسخة مستقلة من الكود للعرض والمراجعة، بتاريخ جديد لا يمثل تاريخ تطوير المستودع الخاص. لا تحتوي على بيانات العملاء أو الطلبات الفعلية أو الصور الخاصة أو مفاتيح الاتصال أو بيانات دخول الموقع المنشور.

الواجهة تضم جولة Three.js تفاعلية تعرض صور المنتجات داخل إطارات ثلاثية الأبعاد، وتقرأ صور وأسعار وتوفر المنتجات المنشورة عند فتح الصفحة. الصور ليست نماذج مجسمة حقيقية للمنتجات. الواجهة موحدة بألوان الكريمي والوردي والذهبي، مع شريط تنقل وكروت Liquid Glass وميل تفاعلي للكروت. وتشمل العربية والإنجليزية، نسخة الموبايل، التصفية، المعاينة السريعة، خيارات المنتجات، السلة، إتمام الطلبات، ولوحة الإدارة.

## التشغيل

```sh
npm ci
npm run setup
npm run dev -- --hostname 127.0.0.1
```

افتح http://localhost:3000. يُنشئ الإعداد بيانات دخول عشوائية خاصة بنسختك في ملف `LOCAL-ACCESS.txt` المستبعد من Git، ولا توجد كلمة مرور مشتركة منشورة. لا تستبدل ملف `.env.local` المُنشأ بملف المثال الفارغ.

بيانات التجربة مستقلة ومحلية. وسائل التحويل المالي غير مفعلة في الإعدادات التجريبية، ولا يوجد اتصال بقاعدة بيانات المتجر الحقيقي. ربط Supabase يحتاج مشروعًا خاصًا بك ومفاتيح محفوظة خارج المستودع.

## التحقق

```sh
npm test
npm run build
```

راجع [الشرح والصور](../README.md) لتفاصيل المميزات وتنظيم الكود. هذه نسخة عرض للكود وليست إذنًا بإعادة استخدام العلامة أو صور المنتجات.
